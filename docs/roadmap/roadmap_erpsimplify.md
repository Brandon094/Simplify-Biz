# Roadmap: Evolución a Vortex ERP 🚀

Este documento detalla el plan estratégico de **ChopCode Solutions** para transformar el sistema en **Vortex ERP**.

---

## Fase 1: Modernización Core & UI/UX (En Progreso) ✅
*Objetivo: Sentar las bases visuales y arquitectónicas.*

- [x] **Identidad Visual:** Implementación de paleta Neon Cyberpunk y Dark Mode.
- [x] **Arquitectura Atómica:** Creación de componentes reutilizables (Atoms, Molecules, Organisms).
- [x] **Navegación Fluida:** Transición de ventanas múltiples a Ventana Única con Sidebar.
- [x] **Dashboard Inteligente:** Métricas en tiempo real conectadas a SQLite.
- [x] **POS Moderno:** Rediseño del módulo de ventas para agilidad en caja.

---

## Fase 2: Robustez y Gestión de Terceros (Próximo Paso) 🏗️
*Objetivo: Completar el ciclo básico de negocio.*

- [ ] **Gestión de Clientes Pro:**
  - Historial de compras por cliente.
  - Gestión de deudas (Cartera) para ventas a crédito.
- [ ] **Módulo de Proveedores:**
  - Registro de compras para entrada de stock.
  - Seguimiento de cuentas por pagar.
- [ ] **Validaciones Avanzadas:** Mejorar el feedback de errores en formularios.

---

## Fase 3: Inteligencia de Negocio & Reportes 📊
*Objetivo: Convertir datos en decisiones para el dueño del negocio.*

- [ ] **Centro de Reportes Avanzado:**
  - Exportación masiva a PDF/Excel con plantillas premium.
  - Reporte de utilidades reales (Venta - Costo).
  - Identificación de productos "Top Sellers".
- [ ] **Alertas de Inventario:** Notificaciones automáticas (Toasts) cuando un producto llegue a stock crítico.

---

## Fase 4: Escalabilidad & ERP Multiusuario 🏢
*Objetivo: Adaptar el software para empresas con múltiples sedes o necesidades complejas.*

- [ ] **Soporte Multicaja / Multisucursal:** Preparar la base de datos para manejar locales diferentes.
- [ ] **Migración Opcional a Cloud:** Soporte para MySQL/PostgreSQL remoto para acceso desde cualquier lugar.
- [ ] **Módulo de Gastos:** Registro de gastos operativos (arriendo, servicios, nómina) para balance general.

---

## Fase 5: Preparación para la Venta (Go-to-Market) 💰
*Objetivo: Empaquetado profesional para pago único.*

- [ ] **Instalador Profesional:** Crear un ejecutable (`.exe` / `.deb`) con instalador que incluya el JRE.
- [ ] **Licenciamiento:** Sistema simple de activación por llave para el pago único.
- [ ] **Documentación de Usuario:** Manual interactivo dentro de la app.

---

> **Visión Final:** Vortex ERP no será solo una base de datos de productos, sino el cerebro de la empresa, permitiendo a cualquier tendero o dueño de PYME profesionalizar su negocio con un solo pago.
