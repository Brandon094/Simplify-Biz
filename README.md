# **✨ Vortex ERP (by ChopCode Solutions) ✨**

**Vortex ERP** is a high-level business management ecosystem designed for SMEs, retail stores, and modern businesses.
💻 Developed in **Java 17** with a **Swing** graphical interface and a **SQLite** database, it offers a role-based system and efficient data management through specialized modules.

---

## **📋 System Requirements**

The application is developed in **Java 17** and is portable. You only need to have JDK 17 or higher configured on your system.

---

## **🗄️ Database Management**

📂 Vortex ERP uses a portable SQLite database. Upon first launch, the system will ask you to select a location for the `db.sqlite` file. This allows for easy backups and portability.

🔎 On initial run, the system verifies if an administrator exists. If not, it will guide you through a modern registration process to set up your primary secure account.

---

## **🚀 Getting Started**

### **1️⃣ Run from Executable JAR**
- ✅ Ensure JDK 17+ is installed.
- 📁 Double-click the JAR file: **`Simplify-Biz-1.2.0.jar`**.

### **2️⃣ Run from Terminal**
```bash
java -jar Simplify-Biz-1.2.0.jar
```
